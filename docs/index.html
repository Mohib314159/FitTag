Camera settings +

We use 35 mm equivalent focal length from the photo when available. Otherwise we assume an 84° diagonal field of view. That assumption can change every centimetre result.

    Why this is an experiment +

    One image does not uniquely determine physical size. Learned metric depth adds a statistical prior, not a ruler. Similar-looking photographs can represent differently sized garments.

    A small indoor depth model proposes metres. We test a floor plane, reject bad geometry and can compare two independent captures. Shared model bias survives all those checks.

    Counterexample: on six simulated captures, unanchored depth had substantial scale error—even with a well-fitting floor plane. The example shows that failure directly.

    The simulated example is an actual model run. It is not real-garment validation. Paper/button evidence from the main app does not validate this mode.
